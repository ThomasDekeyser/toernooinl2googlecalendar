# CSV → XML Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the toernooi.nl URL fetch in `CalendarSynchronizer.execute()` with an in-memory conversion of `data/tmp/matches.csv` into the JOOX `Document` the existing sync already consumes.

**Architecture:** Add pure static helpers (team-name cleanup, date reformat) and a `buildDocumentFromCsv` builder that groups each match under both teams and constructs the `<teams>` document with JOOX's `$(name, children...)` API. `execute()` reads a CSV path from a new `<matchesCsv>` config element instead of an HTTP URL.

**Tech Stack:** Java 8, JOOX 1.1.0 (`org.jooq:joox`), JUnit 4 + Hamcrest, Maven.

## Global Constraints

- Java source/target level: **1.8** (no `var`, no records, no `List.of`, no text blocks).
- XML must be built with **JOOX** (`import static org.joox.JOOX.$;`).
- Output XML structure (root `<teams>`, `<team name>` → `<event>` with `matchId`, `subject`, `location`, `startDateTime`, `endDateTime`) is FIXED — it is consumed unchanged by `syncTeams()` / `addEventIfNeeded()`.
- Test package must be `be.gentsebc.calendar.sync` (helpers/builder are package-private, called directly from tests).
- `pboCompetitionId` config stays (used by `ToernooiNlGrapper` for location scraping). Only the `<pbo>` URL element is removed.

## Verified facts (already checked against joox-1.1.0.jar during planning)

- `$(String name)`, `$(String name, String content)`, and `$(String name, org.joox.Match... children)` all create elements. `$("teams", teamMatchArray).document()` returns a `Document` whose `documentElement` is `<teams>`, and `$(doc).xpath("//team")` finds the teams — the exact call `syncTeams()` uses.
- `$("location", "")` serializes as `<location/>` and `.find("location").content()` returns `""`.
- Downstream parser `new SimpleDateFormat("dd/MM/yyyy HH:mm:ss")` **leniently** parses single-digit output like `20/9/2026 19:00:00` and `2/9/2026 9:05:00`.
- Input `d-M-yyyy H:mm:ss` → output `d/M/yyyy H:mm:ss`: `20-9-2026 19:00:00` → start `20/9/2026 19:00:00`, end (+3h) `20/9/2026 22:00:00`.
- CSV column indices (0-based, `;`-split): `matchid`=1, `team1name`=11, `team2name`=13, `plannedtime`=16.

        return XML_OUT.format(CSV_IN.parse(plannedTime));

Add to `CalendarSynchronizer` a private row holder and the builder method:

```java
    private static final class EventRow {
        final String matchId;
        final String subject;
        final String start;
        final String end;
        EventRow(String matchId, String subject, String start, String end) {
            this.matchId = matchId;
            this.subject = subject;
            this.start = start;
            this.end = end;
        }
    }

    static Document buildDocumentFromCsv(String csvPath) throws IOException, ParseException {
        List<String> lines = Files.readAllLines(Paths.get(csvPath), StandardCharsets.UTF_8);
        Map<String, List<EventRow>> teamToEvents = new TreeMap<>();

        for (int i = 1; i < lines.size(); i++) { // skip header
            String line = lines.get(i);
            if (line.trim().isEmpty()) {
                continue;
            }
            String[] c = line.split(";", -1);
            if (c.length < 17) {
                continue;
            }
            String matchId = c[1];
            String team1 = stripTeamIndex(c[11]);
            String team2 = stripTeamIndex(c[13]);
            String plannedTime = c[16];
            String subject = team1 + " - " + team2;
            EventRow row = new EventRow(matchId, subject, toXmlStart(plannedTime), toXmlEnd(plannedTime));

            teamToEvents.computeIfAbsent(team1, k -> new ArrayList<>()).add(row);
            teamToEvents.computeIfAbsent(team2, k -> new ArrayList<>()).add(row);
        }

        List<Match> teamElements = new ArrayList<>();
        for (Map.Entry<String, List<EventRow>> entry : teamToEvents.entrySet()) {
            List<Match> eventElements = new ArrayList<>();
            for (EventRow row : entry.getValue()) {
                eventElements.add($("event",
                        $("matchId", row.matchId),
                        $("subject", row.subject),
                        $("location", ""),
                        $("startDateTime", row.start),
                        $("endDateTime", row.end)));
            }
            teamElements.add($("team", eventElements.toArray(new Match[0])).attr("name", entry.getKey()));
        }
        return $("teams", teamElements.toArray(new Match[0])).document();
    }
```
